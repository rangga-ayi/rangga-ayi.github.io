# Portfolio

```bash
# Dev
open index.html

# Deploy
git push origin main
```

## Stack
- **HTML** — no framework
- **Tailwind** (CDN) — utility-first
- **Lucide** — icons
- **Nunito** + **Fredoka** — typography
- **Formspree** — form backend
- **GitHub Pages** — hosting

## Folder structure
```
/
├── index.html     # landing page
├── style.css      # overrides
├── PRD.md         # product requirements
└── assets/        # images
```

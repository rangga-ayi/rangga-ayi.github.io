Proyek 01 · Aplikasi Web & Database

Alzi Petshop: E-Commerce & Payment Gateway

Peran saya

Backend PHP & MySQL, Skema DB, RBAC, API Webhook & Fulfillment

Kolaborasi Git

110 commit oleh saya (69,6%), 48 commit oleh rekan (30,4%)

Status

Selesai, diuji penuh & terdokumentasi di GitHub

Backend PHP & MySQL dengan desain database relasional, logika CRUD terparameter, RBAC multi-peran, dan endpoint webhook API.

Merancang arsitektur server-side dan skema relasional MySQL menggunakan query terparameter (prepared statements) untuk mencegah SQL injection, validasi input, serta Role-Based Access Control (Admin, Penjual, Pembeli). Terintegrasi dengan Midtrans Snap API melalui endpoint HTTP POST webhook bervalidasi SHA-512, pemetaan ongkos kirim OpenStreetMap, dan invoice PDF Dompdf.

Alur arsitektur sistem

Transaksi, keamanan, dan pemenuhan pesanan.

Pilih tab di bawah untuk melihat bagaimana data dan keamanan diproses pada backend Alzi Petshop.

Dari checkout hingga verifikasi webhook server-to-server.
Keranjang Belanja → Snap Token Request → Midtrans Payment → Webhook Notification → Database Lunas

Pengguna memilih metode bayar pada pop-up Midtrans Snap. Setelah pembayaran selesai, server Midtrans mengirimkan HTTP POST webhook dengan signature SHA-512 ke backend PHP untuk validasi otomatis status pesanan tanpa celah bypass browser.

Role-Based Access Control dan parameterisasi query.
Login & Sanitasi → Prepared Statement → Verifikasi Session Role → Akses Admin / User

Mencegah SQL Injection dengan prepared statements. Setiap request melewati middleware pengecekan peran (Admin, Penjual, Pembeli) sehingga data transaksi dan hak kelola toko terisolasi secara aman.

Penentuan titik kirim geolokasi dan penerbitan bukti invoice PDF.
Koordinat Alamat → OpenStreetMap API → Kalkulasi Tarif Kirim → Generate PDF Dompdf

Pelanggan menentukan lokasi penerimaan via peta interaktif OpenStreetMap. Setelah pesanan dikonfirmasi, sistem backend mengompilasi bukti bayar berformat PDF resmi menggunakan library Dompdf.

Proyek 02 · Prototype Hardware & IoT

Smart Locker Kompartemen Kos Berbasis RFID & OTP Telegram

Peran saya

Ide & perancangan, perakitan hardware, wiring sirkuit, firmware FreeRTOS & Bot Telegram

Komponen & Platform

ESP32, FreeRTOS, ESP32-CAM, RFID RC522, 3× VL53L0X, Keypad 4×4, LCD, Relay, Solenoid 12V

Pengujian & Status

14 skenario blackbox autentikasi (100% lulus), stabilitas tegangan 3,34–3,35 V

Loker penitipan paket otomatis berbasis ESP32 dual-core dengan foto kurir dan OTP sekali pakai via Telegram.

Prototype fasilitas penitipan dan penyimpanan paket untuk penghuni kos saat tidak berada di kamar. Kurir memasukkan nomor loker, difoto secara otomatis oleh ESP32-CAM, lalu notifikasi dan tombol buka dikirim ke Bot Telegram penghuni; akses pengambilan menggunakan kartu e-KTP/RFID terdaftar atau kode OTP via keypad.

Dokumentasi hardware & pengujian

Purwarupa fisik, pembaca RFID, dan notifikasi Bot Telegram.

Catatan Proyek: Smart Locker merupakan prototype rekayasa perangkat keras (perlu kalibrasi sensor jarak VL53L0X dengan galat ukur 2–17,7%) dan belum diimplementasikan secara komersial.

Alur kerja sistem

Transaksi, hak akses, dan pengiriman pesanan.

Dari checkout hingga update status bayar otomatis dari Midtrans.
Keranjang Belanja → Request Token Snap → Pembayaran Midtrans → Notifikasi Webhook → Status Lunas di DB

Pembeli membayar lewat pop-up Midtrans Snap. Setelah transaksi selesai, Midtrans mengirim webhook berverifikasi SHA-512 ke server PHP untuk memperbarui status pesanan di MySQL menjadi lunas.

Pembagian hak akses pengguna dan keamanan query database.
Login & Cek Input → Prepared Statement → Cek Session Role → Halaman Sesuai Peran

Menggunakan prepared statements agar aman dari SQL injection. Setiap halaman memeriksa session login dan peran akun (Admin, Penjual, Pembeli) supaya hak kelola dan data transaksi tidak tercampur.

Penentuan lokasi kirim di peta dan cetak bukti invoice PDF.
Pilih Alamat Kirim → OpenStreetMap → Hitung Ongkir → Cetak PDF Dompdf

Pembeli memilih alamat kirim di peta OpenStreetMap untuk menghitung ongkos kirim. Setelah pembayaran masuk, sistem membuat invoice PDF dengan Dompdf.

Smart Locker Kompartemen Kos Berbasis RFID & OTP Telegram

Peran saya

Ide & perancangan, perakitan hardware, wiring sirkuit, firmware FreeRTOS & Bot Telegram

Komponen & Platform

ESP32, FreeRTOS, ESP32-CAM, RFID RC522, 3× VL53L0X, Keypad 4×4, LCD, Relay, Solenoid 12V

Pengujian & Status

14 skenario blackbox autentikasi lulus, stabilitas tegangan 3,34–3,35 V

Loker penitipan paket otomatis berbasis ESP32 dual-core dengan foto kurir dan OTP sekali pakai via Telegram.

Prototype loker penitipan paket untuk penghuni kos saat sedang tidak di kamar. Kurir memasukkan nomor loker, difoto otomatis oleh ESP32-CAM, lalu notifikasi dan tombol buka dikirim ke Bot Telegram penghuni; akses pengambilan memakai kartu e-KTP/RFID terdaftar atau kode OTP di keypad.

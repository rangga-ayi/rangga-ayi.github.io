TUGAS AKHIR 2026 HKI KEMENKUMHAM RI FreeRTOS Dual-Core

Smart Locker 3-Kompartemen: FreeRTOS, e-KTP & OTP Telegram

Prototipe loker mandiri (standalone) 3 pintu berbasis ESP32 FreeRTOS Dual-Core (Core 0: Jaringan WiFi & Bot Telegram; Core 1: Hardware I/O real-time). Mengintegrasikan autentikasi ganda e-KTP (RFID RC522) dan OTP Telegram 4-digit (auto-burn), dokumentasi foto kurir ESP32-CAM (UART), deteksi paket laser 3x VL53L0X ToF (I2C 50 kHz) via PCF8574, sensor pintu MC-38, relay solenoid 12V, mode admin lokal keypad 4x4 + LCD 16x2, serta penyimpanan offline NVS ESP32.

ESP32 & ESP32-CAM FreeRTOS Dual-Core e-KTP RFID RC522 Telegram Bot OTP 3x VL53L0X Laser ToF I2C & PCF8574 NVS Offline Storage Solenoid 12V & MC-38

HOMELAB EXPERIMENT

Lab Keamanan Jaringan: 2-Node Proxmox (Red vs Blue Team)

Eksperimen infrastruktur jaringan lokal menggunakan 2 laptop fisik ber-hypervisor Proxmox VE. Area A (Defender) menjalankan VM Web Server, DNS Server, Wazuh SIEM Server, serta router/firewall pfSense. Area B (Attacker) menjalankan router pfSense dan Kali Linux dengan tools hping3, hydra, dan nmap. Dilengkapi analisis troubleshooting firewall host dan deteksi event log SIEM.

Proxmox VE pfSense Firewall Wazuh SIEM Kali Linux hping3 & Nmap
